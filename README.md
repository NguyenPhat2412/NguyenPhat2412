## 👨‍💻 Engineering Approach

I design and build connected software systems end-to-end — from responsive client interfaces to real-time event pipelines and cloud infrastructure.

- **Clear service boundaries** — typed API contracts, explicit authentication/validation, and maintainable domain models.
- **Real-time & event-driven** — low-latency state synchronization with WebSocket, Socket.io, GeoJSON streams, and Apache Kafka.
- **Production discipline** — containerization, automated CI/CD workflows, observability, and measurable performance.
